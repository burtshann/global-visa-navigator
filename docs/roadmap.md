# 实施路线图

| 阶段 | 范围 | 验收 |
| --- | --- | --- |
| 首轮原型 | 项目、目录、问卷、基础比较、少数路径的可解释规则和来源变动检查 | 九国可浏览，有规则的路径显示依据和缺口，未知信息保留为未定，规则版本和测试可审计 |
| 第二阶段 | 三值规则表达式、目标匹配、德国机会卡核对、PostgreSQL 读取及最小审核流程 | 条件判断可追溯，待核验路径仅供浏览，政策须经人工批准，端到端验证结果呈现 |
| 政策深化 | 逐项核验英国 Skilled Worker、加拿大 Express Entry 和新加坡 Employment Pass | 记录官方原文、生效边界和证据，先编写边界测试再发布对应规则 |
| 政策监测 | 来源检查定时运行、人工队列和差异审阅 | 来源变化生成审核事项，测试覆盖生效切换、历史版本和采集失败 |
| 比较与扩展 | 深化跨国对照和缺口行动，扩充各国路线，按需支持用户主动保存 | 按国家和路径类型浏览适合的选择，在明确授权下保存资料并支持删除 |

路线扩充以官方证据可获得性和核验成本为优先顺序。每次启用新规则附带能够证实边界情况的测试和规则级官方来源。收到政策更新时先评估影响范围，再安排复核及发布。
