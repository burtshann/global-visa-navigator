# 产品需求

## 用户与任务

Global Visa Navigator 帮助有跨国工作、求职、技术移民、留学或留学后工作意向的人了解公开的合法签证路径。用户可以用一份问卷在多个目的地进行初步筛选，查看为什么遇到条件缺口，以及应该查看哪份政府指南。

首批目的地为美国、加拿大、英国、德国、澳大利亚、新西兰、日本、韩国和新加坡。目录支持有官方入口但尚未配置规则的国家和路径。发布规则的顺序取决于能否核验政策来源、适用范围和日期。

## 用户流程

1. 从国家目录查看支持的目的地和官方签证入口。
2. 按需填写个人条件和路径目标。对不清楚或暂时不愿提供的答案保留未知状态。
3. 提交问卷后查看与所选目标相关且有可评估规则的路径。未选目标时查看可评估路径，并保留目标未指定的状态。
4. 在个人结果中检查满足项、缺口、未知项及其建议行动。继续按国家和路径类型浏览目录，选择最多三条路径并排比较，打开政府页面核实申请详情。

## 匹配与解释

个人结果根据目标确定路径相关性，以可用规则评估已纳入的条件，并持续提示完整资格仍待核实。结果次序反映已检查条件的状态。待核验的目录路径提供官方入口，不进入个人结果排序。

| 结果 | 含义 |
| --- | --- |
| 已核对条件满足 | 用户答案支持适用的已录入条件，完整资格仍待核实。 |
| 存在条件缺口 | 回答已足以确定录入的必要条件或积分要求存在缺口。 |
| 信息不足 | 当下答案不足以完成一项或多项必要条件检查。 |
| 本组核对条件不适用 | 已提供的资料落在这组核对条件的适用范围之外。 |
| 仅供浏览 | 当前目录条目缺乏有效的已核验规则，或相应规则版本不可用。 |

每项判断绑定路径、政策版本、判定阶段、条件描述、结果和官方来源。下一步行动对应具体缺口，例如补充事实、确认认可资格或阅读主管机关的申请指南。排序、标签或进度指示不得暗示成功概率。

当前规则检查聚焦申请阶段，并说明三个阶段的判断范围。

- **申请条件核对**涵盖当前路线和申请场景中已录入的条件。完整申请资格需要核对其余适用要求与证明材料。
- **邀请资格**指某些项目进入候选池或获邀的独立条件。需要邀请的路径应分别报告已核验的入池条件及邀请状态。
- **最终获批**由主管机关根据申请、证明材料和具体情况决定。原型不输出获批预测。

第三阶段扩展到新加坡 EP 新申请的固定月薪和职位邀请，以及英国 Skilled Worker 首次主申请的基础担保和英语条件。申请人仍需核实新加坡 COMPASS 与豁免条件，以及英国对应的职业代码、薪资和其余申请要求。 [第三阶段规则范围](data-model.md#第三阶段新加坡-employment-pass)

## 隐私和可访问性

- 首轮仅采集匹配所需的条件和用户主动填写的可选信息。姓名、联系方式、证件号码、文件上传和详细住址不在问卷范围内。
- 设计以浏览器内的临时问卷为默认。账号、保存和跨设备同步须经单独设计和授权。
- 中英文界面应同时提供可理解的条件说明和状态。官方页面可以保留其原文，翻译不得改变规则含义。
- 目录、问卷、结果和语言切换应支持键盘操作，并可在窄屏中阅读。状态信息以文字和视觉标记共同表达。
- iPhone 私人预览用于验证双语问卷、条件说明、目录比较和清空答案。测试从受访问控制的 HTTPS 链接进入，正式公开之前可在私人环境收集反馈。 [预览配置与验收](testing-deployment.md#iphone-私人预览)

## 后续验收

1. 为各国逐步补齐适用路径，逐条登记可追溯的政策来源、适用场景、版本和核验时间。
2. 扩充跨国比较所支持的路径和字段，逐步覆盖邀请资格等独立判断阶段。
3. 将人工发布记录、来源变更观察及审阅记录接入统一的管理流程。
4. 在现有端到端测试基础上覆盖混合目标，以及更广泛的政策切换场景。
